O Problema

Cloud invisível = carbono invisível

🔴 O cenário atual

  • Data centers representam 2-4% das emissões globais de CO₂
  • Empresas não sabem quanto carbono sua infra emite
  • Recursos ociosos geram custo E poluição
  • Ferramentas de custo ignoram impacto ambiental

🎯 ODS Atendida

ODS 13 — Ação contra a mudança global do clima

Medir para reduzir. Sem visibilidade, não há como agir de forma consciente sobre emissões de infraestrutura digital.

🌍 ODS 13 · Meta 13.3
💻

Solução Proposta

CLI + Dashboard que traduz infra em pegada de carbono

⚡ O que é o Carbon Lens

  • Ferramenta CLI estilo terminal (TUI) que escaneia recursos AWS
  • Correlaciona uso de recursos com emissões de CO₂ por região
  • Gera relatórios com sugestões de otimização verde
  • Dashboard web com métricas em tempo real

Resultado Esperado

Impacto mensurável em 3 frentes

🌿 Redução de CO₂

  • Identificar recursos que emitem sem necessidade
  • Sugerir rightsizing e regiões mais verdes
  • Meta: -30% de emissões em 6 meses

💰 Redução de Custos

  • Recurso ocioso = gasto desnecessário + emissão
  • Otimização verde = otimização financeira
  • Meta: -25% na fatura cloud

📈 Eficiência Operacional

  • Visibilidade em tempo real para decisões rápidas
  • Relatórios automáticos para compliance ESG
  • Integração no workflow DevOps existente

🏆 Cultura Green Cloud

  • Conscientização do time sobre impacto ambiental
  • Métricas de carbono no CI/CD pipeline
  • Score verde por equipe/projeto
🚀

Diferencial

Por que não basta usar ferramentas tradicionais

❌ Ferramentas tradicionais

  • CloudWatch, Cost Explorer = só custo
  • AWS Carbon Footprint Tool = descontinuada (CCFT)
  • Não correlacionam custo ↔ carbono
  • Interface web pesada, sem automação CLI

✅ Carbon Lens

  • CLI-first — integra com scripts e CI/CD
  • Correlação custo × carbono — visão unificada
  • Sugestões actionable — não só dados, ações
  • Open-source — comunidade + transparência
  • Tempo real — não relatório mensal atrasado

💡 Nenhuma ferramenta open-source hoje oferece visibilidade de carbono por recurso com interface CLI para DevOps. Carbon Lens preenche essa lacuna.
